# 美股组合的标普 500 股指期货对冲策略与样本外回测

用一个 **USD 25,000,000 的 18 只美股组合**，做**空头 E-mini S&P 500 期货**对冲，比较「不对冲 / 最小方差（MV）/ CAPM」三种策略在 **2025 年样本外**的风险与收益表现，并做交易成本敏感性检验。

> 完整结果见 [`report/Report.pdf`](report/Report.pdf)（5 页总结报告）与 [`report/Poster.pdf`](report/Poster.pdf)（海报）。全部代码、数据与图表均可离线复现。

---

## 一、研究设计

| 项目 | 设置 |
|---|---|
| 客户 | 美国机构投资者，持有一个分散化的美股组合，预期未来 3–12 个月市场下跌，希望在不清仓的前提下对冲系统性风险 |
| 股票组合 | 18 只跨行业美股，每组合初始 USD 25,000,000：科技 5（AAPL、MSFT、NVDA、GOOGL、AMZN）· 金融 3（JPM、V、MA）· 能源 2（XOM、CVX）· 消费 4（PG、KO、WMT、MCD）· 医疗 2（JNJ、UNH）· 工业 2（CAT、HON） |
| 权重方案 | 等权（1/18）与市值加权 |
| 对冲工具 | CME E-mini S&P 500 期货（ES），合约乘数 USD 50 / 指数点 |
| 市场代理 | SPY（复权价，总回报口径） |
| 估计期 | 2023-01-01 – 2024-12-31（502 个日度观测） |
| 评估期 | 2025-01-01 – 2025-12-31（250 个交易日，**样本外**） |
| 规模 | 2 种权重 × 3 种策略 = **6 条回测组合** |

## 三、对冲比率

### 最小方差（MV）

把组合每日美元盈亏 `X` 与一张期货的每日美元变化 `Y`（已乘 50）回归，斜率即最优空头手数：

```
N*_MV = Cov(X, Y) / Var(Y)
```

### CAPM

按组合 Beta 做名义价值覆盖：

```
N_CAPM = β_P · V_P / V_F ,   β_P = Σ w_i·β_i ,   V_F = 50 × F0
```

组合 Beta（L2 以 SPY 为市场代理估计）：等权 **0.7817**，市值加权 **1.2264**。

### 估计结果（L3）

| 组合 | 持仓假设 | 方法 | 手数 |
|---|---|---|---|
| 等权 | 买入持有 | MV | **60 SHORT** |
| 等权 | 月度再平衡 | MV | 63 SHORT |
| 等权 | 季度再平衡 | MV | 64 SHORT |
| 市值加权 | 买入持有 | MV | **88 SHORT** |
| 等权 | 目标权重 | CAPM | **66 SHORT** |
| 市值加权 | 目标权重 | CAPM | **103 SHORT** |

主回测（L4）使用「买入持有」的 MV 与 CAPM 手数：**60 / 66 / 88 / 103**。

## 四、样本外结果（2025 年，毛收益口径）

| 组合 | 策略 | 手数 | 全年盈亏 | 收益率 | 日盈亏波动 | 方差降低 | 最大回撤 |
|---|---|---:|---:|---:|---:|---:|---:|
| 等权 | 不对冲 | 0 | +$4.48M | +17.94% | $229k | — | −14.00% |
| 等权 | MV | 60 | +$2.28M | +9.12% | $89k | **84.78%** | **−3.88%** |
| 等权 | CAPM | 66 | +$2.06M | +8.24% | $89k | 84.83% | −4.37% |
| 市值 | 不对冲 | 0 | +$5.67M | +22.66% | $331k | — | −21.61% |
| 市值 | MV | 88 | +$2.43M | +9.74% | $117k | **87.50%** | −4.66% |
| 市值 | CAPM | 103 | +$1.88M | +7.53% | $121k | 86.64% | −4.20% |

**三个结论**

1. **风险显著下降**：日度盈亏方差降低 **84.78%–87.50%**，最大回撤由 −14.0% / −21.6% 收窄至 −3.9% / −4.7%。
2. **下跌保护有效**：在 107 个真实下跌日（SPY 收跌），等权组合由 **−$137,303/天** 转为 **+$7,244/天（MV）** 或 **+$21,699/天（CAPM）**。
3. **代价是牛市收益腰斩**：2025 年整体上涨，做空期货拖累收益，等权组合 +17.94% → +9.12%。对冲的本质是**用收益换稳定**。

## 五、交易成本敏感性

按 **9 次单边交易**（1 次建仓 + 4 次换月 × 2 腿）计费，分四档：

| 情景 | 每张每边成本 | 假设 |
|---|---:|---|
| 零成本 | $0 | 基准 |
| 低 | $3.00 | 仅佣金 |
| 中 | $9.25 | 佣金 $3 + 半价差 $6.25 |
| 高 | $15.50 | 佣金 $3 + 整价差 $12.50 |

最高成本档下，四种对冲策略全年费用为 **$8,370 – $14,368**，对 USD 2,500 万组合而言净收益率仅下降约 **0.03–0.06 个百分点**，方差降低率与最大回撤基本不变。结论对成本假设稳健。

## 八、局限

1. 换月盈亏按 `PX_LAST` 日终价计算，未按真实可成交价核验，**不能保证无滑点成交**。
2. 未模拟期货保证金占用与股票现金分红的实际现金流。
3. 牛熊标签为自定义规则（过去 20 日 SPY 收益 ±3%），非官方分类；代表性区间为事后选取，不构成可交易择时规则。
4. 成本为情景假设（基于佣金与买卖价差估计），非实际成交回单。

> 因此本仓库结论应理解为**方法论演示与样本外检验**，而非可直接实盘执行的对冲方案。
